# Изменения

## 0.1.3

- Российские домены в INCY разрешаются обычным DNS Яндекса (77.88.8.8).
  Прежний адрес DoH Яндекса не отвечал, и INCY ждал таймаут DNS около 4 секунд
  перед каждым новым соединением. Существующая настройка исправляется при
  `sudo ruavc update`.
- `routing.remote_dns` и `routing.domestic_dns` допускают пустое значение:
  обычный DNS на `*_dns_ip`.

## 0.1.2

- Профиль маршрутизации INCY больше не ссылается на `geosite:ru-inside`:
  российские домены передаются явным списком. INCY для Windows применял
  профиль со своим встроенным geosite.dat без этой категории, и Xray не
  запускался («failed to check code RU-INSIDE»).
- Ревизия geo-данных определяется через git вместо GitHub API: установка и
  обновление правил не упираются в лимит API на общих IP-адресах.

## 0.1.1

- Установка на Ubuntu больше не откатывается сразу после запуска служб:
  проверка ждёт, пока Xray и nginx действительно начнут принимать соединения.
- Журнал `/var/log/ruavc/manager.log` создаётся и на Ubuntu, где `/var/log`
  принадлежит группе syslog.
- При откате изменения в терминал выводится замаскированная причина ошибки.
- Служба подписок перезапускается без ошибки создания временных каталогов nginx.
- CI проверяет полную установку через systemd на Ubuntu 22.04/24.04/26.04,
  amd64/arm64.

## 0.1.0

- Новая реализация менеджера личного VLESS Reality VPN для INCY.
- JSON-конфигурация, отдельные секреты и credentials устройств.
- Транзакционное применение поколений, rollback, boot recovery и backup.
- Управление Reality target, SNI, портами, fingerprint, ключами и shortId.
- Проверка target на совместимость с REALITY: TLS 1.3, X25519 и размер первого
  ответа TLS не больше 8192 байт.
- `direct on/off` и пользовательские правила с приоритетом proxy.
- Быстрый status без секретов и диагностика по слоям с VLESS self-test;
  при ошибке self-test в журнал пишется замаскированный вывод Xray.
- Независимые обновления программы, Xray и российских наборов маршрутизации.
- Проверки Ubuntu 22.04/24.04/26.04, amd64/arm64 в CI; release зависит от тестов.
