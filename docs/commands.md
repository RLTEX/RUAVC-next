# Команды

Все операции с установленным сервером требуют `sudo`.
`ruavc help` и `ruavc version` доступны без root.

| Команда | Результат |
|---|---|
| `status [--json]` | Быстрое локальное состояние, имена устройств без credentials |
| `add ИМЯ` | Новое устройство; успех только после проверки подключения |
| `qr ИМЯ` | Явное раскрытие ссылки и QR |
| `link ИМЯ` | Только ссылка; подходит для защищённой автоматизации |
| `reissue ИМЯ` | Новые UUID и token; старый доступ прекращается |
| `revoke ИМЯ` | Удаление UUID и обоих endpoints устройства |
| `direct [on\|off]` | Прямой доступ к российским ресурсам |
| `sites` | Текущие пользовательские правила |
| `sites add direct\|proxy ЗАПИСЬ` | Добавление домена, IP, CIDR или geo-категории |
| `sites remove direct\|proxy ЗАПИСЬ` | Удаление правила |
| `sites edit` | Редактирование временной копии в nano/vi с проверкой до применения |
| `sites import` | Чтение полного списка из stdin |
| `config` | JSON настроек без ключей и credentials |
| `config set КЛЮЧ ЗНАЧЕНИЕ ...` | Атомарное применение нескольких параметров |
| `country [КОД\|auto]` | Страна в названиях INCY |
| `reality check` | DNS, TCP, TLS 1.3, сертификат SNI, HTTP/2 |
| `reality auto` | Повторный выбор проверенного target |
| `reality rotate-keys` | Новая пара Reality keys, сохранение shortId |
| `reality rotate-short-id` | Новый shortId |
| `reality import-keys` | JSON с ключами через stdin |
| `doctor [--json]` | Диагностика по слоям; ошибки отделены от непроверенных условий |
| `logs [--lines 60]` | Маскированный журнал операций |
| `check-update` | Версии RUAVC и Xray |
| `update [ruavc\|xray\|routing]` | Раздельное обновление компонента |
| `backup create\|list` | Полный переносимый backup / список архивов |
| `backup restore ИМЯ_АРХИВА` | Проверка и применение архива из `/var/backups/ruavc` |
| `rollback` | Предыдущее рабочее состояние с новой ревизией маршрутизации |
| `recover` | Восстановление по журналу прерванной транзакции |
| `repair` | Пересборка генерируемых файлов из проверенных исходных документов |
| `uninstall --yes` | Удаление RUAVC с сохранением полного backup |

Имя устройства: 1–40 букв, цифр, дефисов и подчёркиваний; кириллица поддерживается.
Имена не используются как пути или команды.

## Параметры config

| Ключ | Значение |
|---|---|
| `server.address` | Публичный адрес, используемый клиентами |
| `server.country` | Код страны из двух букв |
| `reality.port` | Входящий TCP-порт; отличается от web.port и 80 |
| `reality.target` | TLS-назначение `host:port` |
| `reality.sni` | Имя в сертификате target |
| `reality.fingerprint` | `firefox`, `chrome`, `safari`, `ios`, `android`, `edge`, `360`, `qq`, `random`, `randomized` |
| `reality.flow` | Пустая строка (по умолчанию) или `xtls-rprx-vision` |
| `web.domain` | Домен HTTPS подписок; потребуется сертификат |
| `web.port` | Порт HTTPS подписок |
| `routing.direct` | `on/off` или `true/false`; то же, что `direct` |
| `routing.interval_hours` | Интервал загрузки наборов, 1–168 часов |
| `routing.remote_dns`, `routing.domestic_dns` | URL DoH; пустое значение — обычный DNS на `*_dns_ip` |
| `routing.remote_dns_ip`, `routing.domestic_dns_ip` | IP для bootstrap DNS |
| `routing.geoip_repository`, `routing.geosite_repository` | GitHub-источники с веткой release и SHA-256 |
| `probe_url` | HTTPS-адрес для VLESS self-test, успешный HTTP-ответ |

Пример переключения стандартного HTTPS-порта между компонентами:

```bash
sudo ruavc config set reality.port 2053 web.port 443
```

Для смены домена/порта подписок потребуется новая ссылка на уже существующую
подписку: `sudo ruavc qr ИМЯ`. Изменение публичного адреса или Reality-параметров
требует обновления подписки в INCY. UUID/token при настройке не меняются.

Ввод существующих Reality keys выполняется через stdin из защищённого файла на сервере:

```bash
sudo sh -c 'ruavc reality import-keys < /root/reality-keys.json'
```

Документ содержит поля `private_key`, `public_key`, `short_id`. Пара ключей
проверяется OpenSSL. Значения в аргументах команд не принимаются.

## Пользовательские правила

```text
[напрямую]
example.org
сайт.рф
192.168.50.0/24

[через vpn]
example.ru
```

Поддерживаются домены с поддоменами, IDN, IP/CIDR, `domain:`, `full:`,
`regexp:`, `keyword:`, `geoip:`, `geosite:`. Категория должна существовать в
выбранном наборе. `geosite:ru-inside` в профиль INCY попадает списком доменов:
INCY для Windows использует собственный geosite.dat без этой категории.
Другие категории `geosite:` на Windows зависят от встроенных файлов INCY. Регулярные выражения проверяются Xray/RE2. Ошибочная строка
отклоняет всю операцию, а не исчезает из правил незаметно.

`direct off` сохраняет даже явно добавленное пользовательское `geoip:ru`.
Автоматическая российская маршрутизация и собственные правила независимы.

## Коды завершения

- `0`: операция выполнена или изменений нет.
- `1`: ошибка проверки, сети или системной операции.
- `2`: неверные аргументы/конфигурация или недостаточные права.
- `3`: другая операция держит блокировку; допустим повтор позже.
- `4`: применение и автоматическое восстановление не завершились; нужен `recover`.

`doctor` возвращает `1` при подтверждённых ошибках. `not_checked` не считается
успешной проверкой и отдельно присутствует в JSON. Наличие строки
«Внешняя доступность из РФ не проверена» обязательно.
